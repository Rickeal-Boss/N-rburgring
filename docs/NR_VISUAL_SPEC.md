# 视觉全方位改进规格 — V1（环境 / 物体 / 建筑）

> 依据：`.qa/nr/vis/` 30+ 张巡游实拍（chase 扫掠 ×13、地标 ×6、特写 ×6、真高空俯瞰 ×4、中景 ×3）。
> 结论：**道路/建筑/车辆/HUD 已达观感达标**；短板全在新造环境内容（地形纯绿平面无起伏、
> 地平线一刀切、树单一重复、护栏单薄、建筑立面平淡）。

## 基线（不可改）
- `Renderer/Lighting/Environment/Postfx/vehicles/quality` 数值不动；`src/track/nordschleife.ts` 不动。
- `src/render/scene/roadTexture.ts`（石板三带）**逐字不动** —— 用户口径「画面观感与原先一样」，路板观感是旧仓基线。
- 不引外部资源/CDN；不新增 npm 依赖；全部程序化。
- P0：chase 核显 ≥50FPS、DC ≤180；树/护栏/岩石/灌木必须 InstancedMesh。

## A. 环境核心（最高视觉收益）— `src/render/Landscape.ts` + `src/render/FarHills.ts`
**痛点**：高空俯瞰铁证 —— 地形是无起伏、无颜色变化的纯绿平面；地平线一刀切、远山淡而低。

### A1 地形大尺度色块（杀「绿空洞」最有效一招）
- 给 Landscape 网格加 **vertex colors**：每个顶点按世界 x/z 低频噪声取色
  （浅草 `#6f7d4f` / 深草 `#46523a` / 橄榄 `#7a7a4e` / 干土 `#6b5c40` 平滑混合），
  `material.vertexColors = true`，色偏 ±8%。噪声尺度 ~120~260m 大块，确定性（`makeLcg` 或正弦叠加）。
- `grassTexture()` 升到 **1024²**，追加一层大块低频色斑（80~240px 椭圆，与上同色系，alpha 0.15~0.3），
  保留细颗粒与泥土斑。UV 世界尺度 12m → **40m**（`uv = x/40`），让大块色斑在世界里更大更连贯。
- 目标：从 260m 高空看，地面是**有草甸/林斑/土斑节奏的田野**，不再是纯色地毯。

### A2 地形起伏（中/远场滚动）
- `NOISE_AMP`：`[60,0.8],[120,4.0],[220,7.5],[420,10],[800,14],[1400,18]`（现 0/2.6/4.6/6/12/16）。
- 追加一个 ~35m 波长的高频小起伏（±0.6m，只作用于 |x|>40m），给近中场地表「呼吸感」。
- **铁律**：|x|≤24m 起伏恒 0（不得顶穿路肩/路面）；24→60m 渐入。改后树/岩石/地标自动随
  `terrainPoint` 重落地（同源），但需在 C 阶段复核塔楼/废墟接地。

### A3 地平线层次
- `FarHills.ts`：`H_MIN 60→80`、`H_MAX 140→200`。
- 新增**第二圈外环**（radius ×1.4，高 100~150m，更浅色 `0xa8a89b`，`fog:true`）→ 大气透视两层山脊。
  两圈 = 2 个 mesh / 2 DC。近环色 `0x9a9a86`（略偏绿，读作远森林）。

## B. 物体多样性 — `src/render/Scenery.ts` + `src/render/Track.ts`
**痛点**：树全是同型同色冷杉、护栏立柱稀疏单梁、近场地表只有草。

### B1 树品种/色彩/尺寸
- 新增第二种树（阔叶：`IcosahedronGeometry(1.4,1)` 压扁 ×0.75 作树冠，配短干）独立 InstancedMesh 对。
- 混植：~62% 冷杉（现两锥）/ 38% 阔叶；冷杉色相 0.24~0.32，阔叶色相 0.20~0.30（暖绿），明度 0.14~0.26。
- 尺寸范围放宽：scale 0.6~1.5（现 0.75~1.35）；阔叶冠色 `instanceColor` 同机制。
- 新增 mesh ≤ 2；总数 ~2600 不变（按 62/38 分配）。

### B2 近场地表细节（填空，防「光秃草皮」）
- **灌木**：小 `IcosahedronGeometry(0.5,0)` 深绿，|x|∈[13,28]，~500 棵，InstancedMesh，1 DC。
- **草簇**：小锥/十字面片，|x|∈[12,20]，~800 束，InstancedMesh，1 DC（低饱和黄绿）。
- **巨石簇**：现 300 岩石加 3~5 处 3~5 块成簇（|x|∈[18,60]），并入现 rocks InstancedMesh（只加实例数）。
- 全部 `castShadow=false`、落地用 `terrainPoint`。

### B3 护栏质感
- `Track.ts`：立柱间距 8m→**5m**；横梁改为 **双梁**（y≈0.48 与 y≈0.78，各 0.10 厚）或加高单梁 W 形
  （0.12 厚、0.22 高）。立柱 0.18×0.75→0.16×0.85（更挺拔）。金属灰 `0x8a8f96` 不变。
- 仍是 InstancedMesh（立柱）+ ribbon（梁）；新增 DC ≤ 1。

## C. 建筑立面 — `src/render/Landmarks.ts`（在 A 落地后做）
**痛点**：主殿（s=19500 lat+150）是大片光秃石墙（210m 立面），塔群翼墙平口断面。

### C1 主殿立面细节
- 用 `boxAt`-式组合加：扶壁柱（每 ~12m 一根，0.8×0.8×立面高，前凸 0.5m）+ 尖拱窗龛（
  `castleKit` 的窗形或 box 凹槽，每 24m 一组）+ 檐口压顶（顶沿 0.6m 收边）→ 打破 210m 光墙。
- 复用 ashlar 石砌贴图，材质与现石墙一致；新增 tri ≤ 25k、DC ≤ +2（合并成 1~2 mesh）。

### C2 塔群翼墙端头
- 在 ±57m 裁剪面补 3m 厚端墙帽（+~120 tri、不加 DC）收平口断面。

### C3 接地复核（A2 起伏变化后）
- 塔楼/主殿/大门 `terrainPoint`/`terrainY` 重新落地校验：无浮空/无埋土；偏差>0.3m 即调 sink。

  ⑥ 车在路上、塔楼接地、路板/路缘/车漆无回归。
